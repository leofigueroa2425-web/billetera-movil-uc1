# Billetera Móvil — Proyecto Final UC1

Aplicación Android de billetera virtual que se comunica con un
backend desplegado en Render mediante REST y WebSockets.

## Tecnologías
- Kotlin y Jetpack Compose.
- Room para persistencia local.
- Retrofit y OkHttp para comunicación REST.
- WebSockets para actualizaciones en tiempo real.
- Corrutinas para operaciones de red y base de datos.

## Funcionalidades
- Inicio y cierre de sesión.
- Depósitos.
- Retiros.
- Transferencias entre cuentas.
- Pago de servicios.
- Historial local separado por cuenta.
- Actualización de saldo en tiempo real.

## Cómo ejecutar
1. Descargar el repositorio mediante Code → Download ZIP.
2. Extraer el archivo.
3. Abrir la carpeta del proyecto en Android Studio.
4. Esperar la sincronización de Gradle.
5. Ejecutar en un dispositivo o emulador con Android 8.0 o superior.

La aplicación utiliza el backend desplegado en Render.
